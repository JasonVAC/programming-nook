## 二、阅读程序（共 3 大题，共 40 分）

> 说明：判断题每题 2 分，选择题每题 3 分。

### 第 1 题（共 12 分）

```cpp
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    int sum = 0;
    for (int i = 1; i <= n; i++)
        if (i % 3 == 0 || i % 5 == 0)
            sum += i;
    cout << sum << endl;
    return 0;
}
```

- 判断题：
  1. 程序求的是 1~n 中所有能被 3 或 5 整除的数之和。（　　）
  2. 当 `n = 10` 时，输出为 `33`。（　　）
  3. 该程序的时间复杂度为 `O(n)`。（　　）

- 选择题：
  4. 当 `n = 15` 时，输出为？
     A) 60　　B) 45　　C) 63　　D) 75
  5. 当 `n = 20` 时，输出为？
     A) 90　　B) 98　　C) 100　　D) 105

### 第 2 题（共 14 分）

```cpp
#include <iostream>
using namespace std;
int f(int x) {
    if (x < 10) return x;
    return f(x / 10) + x % 10;
}
int main() {
    int n;
    cin >> n;
    cout << f(n) << endl;
    return 0;
}
```

- 判断题：
  1. 函数 `f` 求的是一个整数各位数字之和。（　　）
  2. `f(0)` 的返回值为 `0`。（　　）
  3. 该递归的深度与 n 的位数成正比。（　　）
  4. 该程序对负数输入也能正确计算其各位数字之和。（　　）

- 选择题：
  5. 若输入 `2024`，输出为？
     A) 6　　B) 8　　C) 10　　D) 24
  6. 该算法的时间复杂度为？
     A) O(n)　　B) O(log n)　　C) O(n²)　　D) O(1)

### 第 3 题（共 14 分）

```cpp
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    int a[105];
    for (int i = 1; i <= n; i++) cin >> a[i];
    int cnt = 0;
    for (int i = 1; i <= n; i++)
        for (int j = i + 1; j <= n; j++)
            if (a[i] > a[j]) cnt++;
    cout << cnt << endl;
    return 0;
}
```

- 判断题：
  1. 程序统计的是数组中逆序对的个数。（　　）
  2. 若数组已按非降序排列，输出为 `0`。（　　）
  3. 程序的时间复杂度为 `O(n log n)`。（　　）
  4. 若把数组所有元素取相反数，程序的输出结果不变。（　　）

- 选择题：
  5. 若输入 `4` 和 `3 1 2 4`，输出为？
     A) 1　　B) 2　　C) 3　　D) 4
  6. 若输入 `4` 和 `4 3 2 1`，输出为？
     A) 4　　B) 5　　C) 6　　D) 12
